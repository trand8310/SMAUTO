# 设备 CDP 大消息处理修复

## 触发问题与修改

`browser-20261013-3760.log` 中 120 次执行在设备控制连接收到超过 4 MiB 的消息后被取消。原来的接收器直接抛 IOException，ConfigureContextAsync 回调统一使用 StartupFailed 关闭浏览器；停止请求发生时这 120 个进程均仍存活。

现已移除 DeviceTargetController 的 Page.enable。该连接只负责 Target 附加/分离与触屏初始化，不使用 Page 事件；业务页面的 CDP session 仍保留自己的 Page.enable。屏幕配置仍由原生 Chromium 处理，不增加尺寸覆盖或 JS 回退。

接收器保留 4 MiB 缓冲上限，超过后继续读取并丢弃剩余分片，直到 EndOfMessage。内存不随消息总长度继续增长。处理完大消息后再接收下一条，避免把残留分片错当成新 JSON。

| 大消息类别 | 处置 |
| --- | --- |
| 已识别的无关事件，例如 Page.frameNavigated | 完整排空，记录元信息，忽略事件；不取消执行 |
| Target.attachedToTarget / Target.detachedFromTarget | 前 64 KiB 内的必要路由元信息完整时，只使用 sessionId、targetId、type，忽略 URL 等正文；保留新页面就绪和旧会话分离规则 |
| 已关联的命令响应 | 仅让对应命令失败，记录其命令名、session 和 ID；单页面初始化按原有策略隔离，关键启动命令则向启动调用方报告失败 |
| 已过期命令响应 | 排空并记录，不影响其他响应 |
| 无法识别路由、或关键 Target 元信息不完整 | 明确报告 DeviceProtocolFailed，不猜测、不丢弃关键状态后继续假定成功 |

路由读取只使用完整解码的 JSON token，支持 WebSocket 分片切开 UTF-8 字符。超过 256 字节的元信息字符串不复制到诊断。大消息正文、URL、页面内容不写日志。

运行期间真正的设备连接断开记录 CdpDisconnected；关键协议数据不可用记录新增的 DeviceProtocolFailed。ConfigureContextAsync 的故障回调保留当前阶段和原始异常，不再把整个浏览期间的控制连接故障统一称为“初始化失败”。失败的接收器释放时跳过无法完成的自动附加关闭命令，直接释放连接，避免额外等待 5 秒。

## 独立日志

继续使用 `logs/browser-lifecycle`。大消息记录 method、bytes、id、session 和处置结果，使用已有的 page.device_diagnostic 事件写入。响应本身没有 method 时，从待完成命令表关联命令名。真正执行级故障另有 page.device_connection_failed，包含阶段、分类和原始异常。

这是针对接收器超限触发误关闭的修复。正常完成、无广告快速结束、TTL、上游取消、代理故障和真实连接失效仍遵守原有结束规则。原日志中的 10 次代理路径失败属于另一条已识别的正常故障处理路径，不通过本修复忽略代理错误。

## 验证

`tests/CdpInput.RegressionTests/DeviceLargeMessageChecks.cs` 使用本地 WebSocket 夹具，发送超过 6 MiB 的中文 payload，分片同时跨越接收缓冲和多字节字符边界。覆盖无关事件后的目标初始化、超大附加/分离事件、单目标超大响应、过期响应、关键启动响应、后续真实连接断开及不记录正文。

真实触屏回归命令：

```powershell
& './tests/CdpInput.RegressionTests/bin/Debug/net8.0/CdpInput.RegressionTests.exe' '../pc_chrome.packed/135.0.7049.119/chrome.exe' --movement
```

本轮 150 项检查通过，包括新增大消息边界和原有真实移动、点击、HTTP、代理及下载夹具。后续补充命令名关联的检查使用同一协议夹具验证。

完整页面流程诊断新增 `--headless=true/false`，仅覆盖本次测试的显示模式，不修改保存配置。完整流程仍拦截所有请求，不访问线上广告网络，也不使用真实代理供应商。生产日志的具体超限事件类型尚不能从历史日志还原，修复后的元信息日志可进一步确认。

`CdpInput.RegressionTests.exe --full-page-flow --rounds=2 --headless=true` 已通过：使用 145.0.7632.110、隐身、TTL 180 秒，爱采购首次新页/二跳同页与 1688 首次同页/二跳新页均完成，详情停留、PV/点击结算和退出确认也通过。报告：`../artifacts/full-page-flow-20261013-092421-07c876e9206e4c519ffd0c07da055b7d/report.json`。

最后的命令名关联修改另通过 `--device-large-messages` 单独验证。MainClient 默认输出目录已构建包含本轮修复。线上真实代理路径与历史日志中具体大消息尚未重放，不能把受控流程结果理解为所有线上站点的长期稳定性证明。
