# SMAd 闲置代码清理（2026-10-09）

本次以当前工作区的调用和字符串引用为依据，清理未进入现有执行流程的方法及其孤立依赖。保留插件元数据入口 GetInfo、任务执行入口、正在使用的落地策略、v3 触摸操作、页面事件和资源回收逻辑。

- 删除 DeviceDisplayProfile.Metrics：SMAd 已不再发送 CDP 尺寸覆盖参数。
- 删除旧 ConnectOverCDPWithRetryAsync、失败累计重启逻辑及对应字段；连接由现有 BrowserRuntimeManager 管理。
- 删除旧滚动判断和 PageScrollState、重复请求判断、未调用的日志标签及京东页面处理分支。
- 删除闲置点击入口、测试滑动方法、CDP 会话查询/预热方法及删除后孤立的辅助方法和数据类型。
- 删除无引用文件 BrowserUiMetrics.cs、ViewportAreaClickHelper.cs、AdTagHelper.cs。
- 删除 SMAdTask 中不再使用的 Win32 和正则命名空间引用。

验证：MainClient 与三个回归项目编译通过；CdpInput 60 项、Step1 24 项、DeviceDisplay 配置 7 项，共 91 项现有检查通过。本次未运行定制 Chromium 的真实浏览器检查，也未修改 Chromium 源码。

屏幕与视口仍由启动参数和定制内核提供，保留只读屏幕/DPR 校验及窗口调整。触摸配置、目标自动附加和等待初始化流程保留。
