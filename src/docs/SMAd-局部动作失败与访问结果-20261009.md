# SMAd 局部动作失败与访问结果

访问结果与点击结果独立：入口页面已就绪并完成停留流程，即完成一次访问。确认没有广告标记时按用户要求走快速完成访问，跳过后续滑动、点击和停留；广告检测失败不能当成没有广告。搜索动作未完成、请求点击但没有确认跳转，不再直接跳过当前页面的停留。点击仍由真实导航或下载结果确认，不以访问成功代替点击成功。

`WorkerExecutionResult.CompletedPvs` 表示完成的访问数，`CompletedClickPvs` 表示其中确认点击的访问数，`ClickRequested` 表示本次执行是否曾请求点击。原来的 `PageTriggerClick` 保留布尔结果，跨 PV 不丢失已确认点击。

SMAd 可选浏览、首跳、落地页和详情操作通过 `OptionalPageOperation` 恢复局部取消、定位超时与可恢复的 Playwright 页面操作错误。恢复前必须确认任务及浏览器会话没有取消、页面仍存活、浏览器仍连接、没有代理故障或页面崩溃。程序错误和会话终止不被当作普通动作失败。

停留中的一次滑动失败后，本轮剩余时间改为静态阅读。单次滑动不超过剩余停留时间。任务取消、页面关闭、浏览器断开或崩溃仍终止执行。浏览器硬生命周期和入口导航失败的处理保持现有行为。

阿里、爱采购及 1688 推荐词预算拆分为：浏览 25000ms，目标筛选 5000ms，点击及导航默认 10000ms，页面就绪后的观察随机 2000–6000ms。筛选预算在进入点击之前解除，观察不消耗导航预算；任务及会话的总取消始终有效。

公共点击无效果或未就绪只保留动作失败结果，不再设置任务级浏览器超时分类，也不自动重试结果不确定的点击。

回归覆盖：局部点击取消、定位超时、无效果不污染浏览器分类、任务取消传播、崩溃及断开不可恢复、滑动超时后继续静态停留、访问与点击独立计数、重复计数防护、跨 PV 点击结果保存，以及导航观察预算隔离。
