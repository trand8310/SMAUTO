# 入口导航与下载计数

页面初始化仍注册一次下载事件，用于取消下载和记录诊断。`BusinessDownloadsEnabled` 初始为 false，每次 PV 重置以及入口导航开始时关闭；入口网页通过 DOMContentLoaded 与 body 可见检查后启用。

禁用期间的下载不增加 `TriggerDownloadSign`，不作为广告点击下载或访问成功。启用期间的下载维持原有业务计数和取消行为，包含后续点击打开的页面。

`EntryPageNavigator` 在入口导航期间暂时记录下载 URL、建议文件名，以及能获取到的主框架响应状态、URL、Content-Type、Content-Disposition 和 Location。导航结束时解绑临时诊断监听。

遇到 `Download is starting` 时，在同一个页面和浏览器内等待随机 800–1400ms，再重试一次。第二次仍转为下载，返回明确的入口未打开结果，由主流程跳过当前 PV，不让该异常直接进入 Worker 的通用异常出口；不无限重试，也不把下载当成打开成功。

部分 Chromium 构建会把附件导航报告为 `net::ERR_ABORTED`。仅在短暂等待后确认存在下载事件或附件响应头时，才将其归类为入口下载；没有证据的导航中断继续抛出。

任务取消及其他真实导航故障继续传播。所有 PV 均未成功打开时，任务仍失败并正常回收浏览器；此次改动不承诺在无有效页面时永久保留浏览器。
