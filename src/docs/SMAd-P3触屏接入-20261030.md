# SMAd 接入 HumanTouchP3（2026-10-30）

SMAd 使用独立的 HumanTouchP3 项目。每次执行按设备稳定种子建立长期画像，再叠加一次持机姿势校准，建立独立的触屏会话；每次会话的随机种子仍独立。`WorkerRunContext`、页面绑定、点击、滑动、文字输入、导航观察、CDP 缓存/失效和滑块触摸统一使用 P3 的同一会话和协调器。单次页面动作失败不负责关闭共享浏览器或其他任务。

没有有效显式姿势时，每次执行独立选择姿势：右手单手 69%、左手单手 13%、左手持机右手操作 18%。任务对象可选传入 `touchPosture`，支持 `RightHandOneHanded`、`LeftHandOneHanded`、`LeftHandHoldRightIndex`，大小写不敏感；有效显式值优先，缺失、非字符串或无效值使用上述随机分布。MainClient 将任务中的该字段传入 SMAd，并记录最终姿势。该选择不改变浏览器原生屏幕参数或业务访问、导航、下载及代理统计流程。

P3 的普通阅读模型会依上下文选择阅读、预览、快扫、微调和回看；动作依旧由已有业务流程触发，输入派发、导航就绪、业务效果和结果计数分别记录。PWTest 的安全制动区是本地夹具，不应用于未知业务页面。

姿势参数依据单台设备和一位操作者的真机记录初步校准，不代表其他人或所有设备。详情见 `docs/HumanTouchP3-真机样本校准-20261030.md`。同一轮触摸和屏幕测试必须使用对应定制内核，本地 Chromium 135 的验证不能替代其他内核的触屏实测。


## 详情与列表浏览

详情停留使用阅读优先的决策，少量回看；停留始终受任务 `SleepMs` 和取消令牌限制，滑动无效果或局部失败时可继续静态阅读，不扩大任务预算。爱采购、1688 与推荐词列表按文档长度决定有界的浏览次数，以向下浏览为主，最多偶尔回看一次；保留总体时间限制。浏览结束后只从当前视口可见、未遮挡的候选中选取，不为候选再执行屏外搜索。长页面仍可能因时间限制、页面边界或滚动失败无法到达底部。
